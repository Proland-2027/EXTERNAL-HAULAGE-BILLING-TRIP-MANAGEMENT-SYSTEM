## Assumptions made

* Model classes: 400-Series / 400SRS = P13–P22; S1 = P33–P46; S2 = P50–P97; S3 = P110–P138;
  S4 = P150–P165; 200–250 / P200/P250 = P200–P275; 350–500 / P350 / P550 = P330–P550; P800 = P600+.
  These were inferred from the BOM (e.g. `SF-SPF-S3-OPT` is the P110 enclosure, `SPF-S2-P88` the
  P88 canopy) and can be edited in `model_classes`.
* Canopy cutting and bending share the "Cutting and Bending / Canopy Cutting" department rate in the
  Canopy Assembly sheet; Punch/Plasma minutes constrain it in addition.
* Process cost groups map to work centres as listed in Masters → Work centres (`operation_map`);
  `IK-PCP` powder coating is routed to Base / Panels / White-goods PWC by component family.
* Transfers between sections become available the next working day in batches of 1 unit (settings).
* Costs are in the workbook's currency (set to NGN in Settings); the ERP standard is dated 2021-02-17.
